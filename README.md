# Pixel Space Savers

**Everett's Pixel Space Savers** is a custom browser arcade game built as an offshoot of the original Pixel Invaders project.

## Current baseline

This first version carries over the working arcade structure so Everett's game has a solid starting point:

- Space-shooter gameplay
- Multiple enemy types and levels
- Score, lives, power, and upgrade system
- Boss levels
- Keyboard and touch controls
- Full-screen support
- Local high scores stored separately for Pixel Space Savers

Everett-specific gameplay, art, enemies, rules, and other changes can now be added on top of this baseline.

## Controls

- **Left / Right Arrow** or **A / D** — move
- **Space** — fire
- **P** — pause
- **R** — restart
- **F** — full screen
